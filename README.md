# CGPA Calculator - V1

This is my first attempt at creating a Cumulative GPA (CGPA) Calculator in C++.

## About the Project

The program calculates a student's CGPA based on the courses they have taken, their credit hours, and their grades.

This was one of my first projects where I tried to apply what I had learned in C++ to a practical problem.

## My First Attempt

At first, I thought I was almost finished with the project. However, after testing the program further, I realized that it was far from being a robust solution.

The code was missing several edge cases, and I also realized that I was lacking some knowledge about how to properly structure and validate the program.

After a lot of trial and error, debugging, and learning, I improved the program significantly.

This repository represents my **first version** of the project. I am also posting the improved version separately to show my progression and what I learned throughout the process.

## What I Learned

- Input validation
- Handling edge cases
- Debugging
- Improving code structure
- Applying C++ concepts to a practical project
- Identifying weaknesses in my own code

## Future Improvements

This version was a learning experience, and there are several areas that can be improved. These improvements are implemented in my second version of the project.
